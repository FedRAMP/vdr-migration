# Submitting Progress Report Updates

!!! bug "This content is pending testing and verification."

    We anticipate providing a way for cloud services to notify FedRAMP that they have completed all necessary corrective action and submit an updated Progress Report to us after the initial data collection.

    We're still considering our options for doing this and will probably not finalize that mechanism until after the Emergency Test to avoid any possible confusion.

We wanted to be sure folks knew that we are planning to allow optional submission of updated information to FedRAMP so we kept in this placeholder page, but for now please monitor the [changelog](changelog.md) for the latest news on this option. We probably won't update this until sometime in January, and will do our best to notify providers about it when we do.
