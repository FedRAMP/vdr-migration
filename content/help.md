# Discussion and Help

FedRAMP primarily provides support for public-facing questions and problems via the FedRAMP Community on GitHub. We prefer to answer questions in public where all members of the community can participate and benefit from the discussion and answers.

## Preferred Way to Get Help

A dedicated thread for discussion is available in the FedRAMP Community on GitHub here:

- [VDR/VER migration progress reporting Q&A/feedback/etc.](https://github.com/FedRAMP/community/discussions/196)

You can use this thread or the built-in comments to ask questions or request clarification. GitHub discussions are a core part of how FedRAMP interacts with the public and allow direct engagement and interaction in a way that ensures all members of the community benefit from the discussion.

These conversations have frequent participation from `@pete-gov` (FedRAMP Director) and `@nicole-gov` (FedRAMP Security Director) among other senior members of the FedRAMP leadership team.

!!! abstract "Built-in Comments"

    This web page also includes a built-in comment system allowing anyone with a GitHub account to comment directly on a specific page.

    These comments are also all posted to the discussions section on the [FedRAMP/VDR-Migration](https://github.com/fedramp/vdr-migration/discussions) repository.

## Private Help

!!! warning "Please always review public discussions on GitHub before engaging with FedRAMP privately."

!!! danger "Do NOT email info@fedramp.gov with VDR/VER migration questions!"

    Please use the form to help us properly categorize, route, and review your message.

If you have a situation that would be irresponsible to discuss publicly, you may ask FedRAMP for help directly. These requests receive a lower priority than public discussions because they only directly benefit one party, though FedRAMP may post a responsible version of your question and the answer publicly if it's relevant to other parties.

Please help us efficiently leverage our limited resources by only directly asking us very specific questions that are not easily answerable in the rules and do not provide value to other stakeholders.

To get help on the VDR/VER Migration, please use this form at [help.fedramp.gov](https://help.fedramp.gov):

- [[CSPs] VDR/VER Migration Progress Report Help](https://help.fedramp.gov/hc/en-us/requests/new?ticket_form_id=58475218319643)
