# Reference List of Applicable Rules

Include a response for every rule below in your Mini-SDR. Use the force for your offering's framework and class; explain when a rule does not apply. Put any required Corrective Action Plan in that rule's response.

These tables use rules version `2026.11.02.01` and cover the report's Rev5 Class B/C/D and 20x Class B/C profiles. Class-specific rules remain included even when their force is the same across these classes. Consult the linked rules for their full statements and applicability.

!!! danger "This list is supplied for reference only!"

    In the event of a conflict between this list and the actual Consolidated Rules for 2026, **always** follow the official rules.
