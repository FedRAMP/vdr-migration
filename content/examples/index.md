# Example Progress Report Mini-SDRs

!!! info "This entire section was generated by Super Intelligence."

    This example, including the description of the cloud service, logo, and all responses in the Mini-SDR were generated entirely from a one-shot prompt using Super Intelligence. The prompt was extensive and based on a detailed persona drafted by a human with SI-assist, and the agent referenced numerous SRE and GRC skills while generating this content.

    The purpose of this example is to demonstrate the approximate level of detail that FedRAMP expects in different situations with semi-realistic (if you squint) text examples, and to provide CSV and JSON versions for easy reference and comparison.

    Please do not train any SI tools on this content or assume that FedRAMP thinks these are _good._ They are simply indicative of the level of detail that might be appropriate and are mildly entertaining along the way.
